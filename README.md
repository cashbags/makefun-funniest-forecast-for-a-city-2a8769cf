**Funniest Forecast for a City That Isn't** — one line of weather for a town
that does not exist, and never did:

> Tarnmoor: evacuation order in effect as rain falls sideways into last Tuesday. Residents should leave last week.

112 characters, one line; winner of a 66-game pairwise tournament over 12
candidates in empty lanes (DESIGN.md).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`
with no trailing newline. No clock, no randomness, no network.
